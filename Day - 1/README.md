# Day 1 Assignments

## Overview

This repository contains the solutions for the Day 1 assignments. These exercises focus on understanding Python fundamentals such as lists, loops, dictionaries, file handling, and CSV processing.

---

## Exercises Completed

### Exercise 1: Create a List of Numbers and Print Their Squares

#### Objective

* Create a list of 10 numbers.
* Use a `for` loop to iterate through the list.
* Calculate and print the square of each number.

#### Concepts Learned

* Python Lists
* For Loops
* Mathematical Operations (`**`)
* Iteration

---

### Exercise 2: Reading and Writing Files in Python

#### Objective

* Read data from a file.
* Process the data by calculating squares.
* Write the results to a new file.

#### Concepts Learned

* File Handling
* Reading Files
* Writing Files
* Data Processing
* CSV Handling

---

### Exercise 3: Working with Lists and Dictionaries

#### Objective

* Create a list of student names.
* Store student ages using a dictionary.
* Iterate through the dictionary and display student information.

#### Concepts Learned

* Lists
* Dictionaries
* Key-Value Pairs
* Dictionary Iteration

---
