# Day 3 Assignments

## Overview

This repository contains the solutions for the Day 3 Machine Learning assignments. These exercises focus on understanding regression models, feature engineering, model comparison, and evaluating machine learning algorithms using real-world datasets.

---

## Assignments Completed

### Assignment 1: Adding Features to California Housing Dataset

#### Objective

* Load the California Housing Dataset.
* Create interaction features between existing variables.
* Train a Linear Regression model using the enhanced dataset.
* Evaluate model performance and compare it with the original model.

#### Concepts Learned

* Feature Engineering
* Interaction Features
* Linear Regression
* Model Evaluation
* Mean Squared Error (MSE)
* R² Score

---

### Assignment 2: Ridge or Lasso Regression on the California Dataset

#### Objective

* Train a Linear Regression model.
* Train a Ridge Regression model.
* Train a Lasso Regression model.
* Compare the performance of all three models.
* Identify the best-performing model.

#### Concepts Learned

* Linear Regression
* Ridge Regression
* Lasso Regression
* Regularization
* Model Comparison
* Performance Evaluation

---

### Assignment 3: Diabetes Dataset Training a Regression Model

#### Objective

* Load the Diabetes Dataset.
* Split the dataset into training and testing sets.
* Train a Linear Regression model.
* Make predictions on test data.
* Evaluate model performance using regression metrics.

#### Concepts Learned

* Regression Modeling
* Dataset Splitting
* Model Training
* Prediction
* Mean Squared Error (MSE)
* R² Score
* Data Visualization
